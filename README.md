# Data · AI Portfolio

## 프로젝트 포트폴리오

### [사용자·기기 기반 접근 통제 및 XDR 경보 분석](projects/security-access-xdr.md)

사용자·기기·자원별 접근 판정, WebAuthn 요청 서명, 6종 합성 보안 경보 분류를 구현한 교육 프로젝트입니다. 문제 정의, 본인 기여, AI 활용, 검증 결과와 커밋에 고정된 코드 링크를 정리했습니다.
